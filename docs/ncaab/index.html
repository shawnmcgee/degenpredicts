How the model was picked

8 models tried · running Huber regression on spreads, Huber regression on totals

Each model was trained on every season before the one it predicted, then scored on 2021-22 to 2025-26 games it never saw. Error is how many points the projected final missed by, on average; lower is better. Side is how often its side of the line won. Of the models whose error is within one standard error of the lowest — a tie, over this many games — the board runs the one whose side won most often.
